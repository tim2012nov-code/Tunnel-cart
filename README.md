## Tunnel Cart 3.0.0 (Minecraft 1.20.1, Fabric)

### Новое
- Кнопка **«Проложить путь» / «Стоп»** в окне вагонетки: теперь она не уезжает сама.
- **Расширение проходчика**: сиденье + склад на 27 слотов, цепляется сзади.
- Поддержка **шалкеров**: вагонетка берёт рельсы и сланец из шалкеров и складывает добычу в них.
- Добыча руд, гравия и глины только в области 5×5.
- Вся оболочка, кроме глубинного сланца, заменяется на колотый глубинный сланец.
- В вагонетку идут только ресурсы и колотый глубинный сланец, остальное падает на пол.
- Новый значок: вагонетка с доменной печью.

### Крафты (бесформенные)
- **Вагонетка-проходчик**: вагонетка с сундуком + алмазная кирка + плавильная печь + блок редстоуна
- **Расширение проходчика**: вагонетка + сундук + дубовые ступеньки

### Требования
Fabric Loader 0.15+, Fabric API 0.92.2+1.20.1. High-Speed Rail по желанию.
