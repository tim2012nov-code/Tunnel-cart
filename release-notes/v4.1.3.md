# Tunnel Cart 4.1.3

## Новое
- Добавлен экран настроек мода, доступный через Mod Menu (если Mod Menu установлен).
- Добавлена настройка скорости вагонетки-проходчика на прямых участках: от 0,1 до 300 блоков в секунду. Значение по умолчанию — 75 блоков/с.
- Добавлена отдельная настройка ограничения скорости обычных вагонеток. Значение 300 блоков/с означает отсутствие ограничения со стороны Tunnel Cart.
- Длина тормозных зон автоматически рассчитывается с учётом выбранной скорости, чтобы вагонетка успевала проходить повороты, подъёмы, спуски и объезды.
- Добавлены предупреждения о рекомендуемой максимальной скорости: значения выше 75 блоков/с могут приводить к нестабильной работе маршрута.

## Настройки
Параметры сохраняются в config/tunnelcart.json. Для доступа к экрану настроек требуется Mod Menu.

## Совместимость
- Minecraft 1.20.1
- Fabric
